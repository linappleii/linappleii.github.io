FAST & MODERN PACKAGING

INSTALLATION & QUICK START

Pre-built native packages and portable binaries are available for Linux x86_64 and ARM64 (Raspberry Pi OS 64-bit / Ubuntu ARM).

Debian / Ubuntu / Raspberry Pi OS (.deb) 
# Download the .deb from Releases and install:
sudo apt-get install ./linapple-latest-linux-x86_64.deb   # on x86_64
sudo apt-get install ./linapple-latest-linux-arm64.deb    # on ARM64 / Raspberry Pi
Fedora / RHEL / AlmaLinux / Rocky Linux (.rpm) 
# Download the .rpm and install with DNF:
sudo dnf install ./linapple-latest-linux-x86_64.rpm
Arch Linux / Manjaro / CachyOS (.pkg.tar.zst) 
# Install via pacman:
sudo pacman -U ./linapple-latest-1-x86_64.pkg.tar.zst
Portable Archive (No Installation Needed) 
tar -xvf linapple-latest-linux-x86_64.tar.gz
cd linapple-latest-linux-x86_64
./bin/linapple --autoboot --d1 share/linapple/Master.dsk
Clone & Build with CMake (SDL3 Default) 
git clone https://github.com/linappleii/linapple.git
cd linapple
cmake -B build -DBUILD_TESTING=OFF
cmake --build build -j$(nproc)
./build/linapple --autoboot --d1 res/Master.dsk

TIERED DECOUPLED DESIGN

CHOOSE YOUR FRONTEND

LinApple features a decoupled architecture with dedicated frontends for every modern and vintage Linux environment.

🚀

SDL3 Frontend (Default)

First-class hardware-accelerated rendering on modern Linux desktops. Native Wayland, X11, and KMSDRM output with high-DPI scaling and silky 60fps NTSC timing.

Wayland X11 KMSDRM
📟

Terminal TUI Frontend

Zero GUI or SDL dependencies. Uses 24-bit Truecolor & Unicode half-block characters to run Apple II games directly inside your standard terminal or remote SSH session!

Truecolor 24-bit SSH Gaming Zero GUI
⚙️

Headless Frontend

Blazing-fast CLI execution with zero audio or video overhead. Designed for automated CI regression testing, test suites, and batch-scripting Apple II tasks.

CI / CD Automated Testing Headless
🕹️

SDL2 & SDL1 Frontends

Full backward compatibility for older Linux distributions, retro handhelds, and vintage embedded systems that lack SDL3 support.

Retro Handhelds Debian 12 Embedded
UNDER THE HOOD

AUTHENTIC HARDWARE EMULATION

Every subsystem faithfully recreates the original Apple II architecture.

SLOT 0

6502 / 65C02 & 128K RAM

Cycle-accurate CPU emulation with auxiliary RAM bank-switching, language cards, and 80-column text hardware.

SLOT 6

Flexible Disk II Engine

Read and write support for .dsk, .do, .po, .nib, .woz v2, plus built-in direct FTP image streaming.

SLOT 7

SmartPort Hard Drives

Massive 32MB storage support with .2mg container parsing and raw .hdv / .po block images for Total Replay and ProDOS.

SLOT 4

Mockingboard & Speaker

Dual AY-3-8910 multi-channel audio synthesis, 6522 VIA timers, standard 1-bit toggle speaker, and WAV audio capture.

MODERN

Applesoft BASIC Live-Sync

Write BASIC in your favorite host editor (VS Code, Vim) and have code synchronize bidirectionally into memory in real time via --basic-sync.

DEBUG

Integrated Debugger

Full assembly disassembler, memory inspector, breakpoint/watchpoint engine, and CPU benchmark accessible via F7.

VINTAGE DISPLAY MODES

AUTHENTIC CRT RENDERING

Experience Apple II software with customizable video modes, scanlines, and authentic artifacting.
